# Coordinated release 0.3.2

Release `v0.3.2` completes the Phase 6 publication after the unsuccessful `v0.3.1` release attempts. It uses RID-aware restore for every platform artifact, the established organization signing secret names, and retry-safe GitHub Release asset uploads.

The coordinated release publishes `murchalka-node-runtime`, `murchalka-module-node-controller`, `murchalka-admin`, `murchalka-node-diagnostics`, and `murchalka-deployment` with the common `v0.3.2` tag. The immutable Protocol, SDK, and central Runtime dependencies remain pinned to their compatible `v0.3.0` releases.
